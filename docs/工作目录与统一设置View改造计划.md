# 工作目录与统一设置 View 改造计划

状态：in progress（2026-08-21 已获用户确认；目录单行试验版）

Owner：KT Auto Code maintainers

## 1. 背景与目标

现有第二个 Shell Block 同时常驻“工作目录”下拉和完整 Ignore 管理，低频规则编辑占用侧栏首屏。用户确认将其收敛为一行工作目录选择，并把 Ignore 放入统一“设置”工具 View 的第一个内部 Block。

这是一项经用户确认的外层职责调整：三个 Shell Block 的数量、顺序和当前工具 `×` 不变；第二 Block 从“工作目录与 Ignore”改为固定的一行“目录”。用户同时确认该行隐藏折叠箭头，因而不再具有独立展开/收起状态。

目标布局：

```text
工具栏
目录  [当前目录 · 名称                                  v] [文件夹] [⚙]
当前工具
  设置（由目录行 ⚙ 打开）
    ▾ Ignore 管理
    ▸ 工程环境
    ▸ 插件设置
```

## 2. 职责与交互

- 第二 Block 只表达和切换共享工作目录：下拉、文件夹选择和唯一设置入口；不常驻显示 Ignore 开关、预设、分析或规则编辑。
- 目录行 `⚙` 打开统一“设置”逻辑工具 View。移除 VS Code View Title 的重复工程环境齿轮，避免同屏两个齿轮。
- 设置 View 的第一个内部 Block 固定为“Ignore 管理”；它保留 Git Ignore 默认生效、插件 Ignore 开关、分析、预设、编辑和从 `.gitignore` 追加的原有语义。
- 工程环境、插件设置等后续内容同样是设置 View 的内部可折叠 Block；它们不得新增 Primary 的第四个 Shell Block。
- 设置 View 内部 Block 的展开状态是本机/会话 UI 状态；不写进工程配置。工作目录和插件 Ignore 的既有持久化位置不变。
- 文件扫描、搜索替换、编码、头文件、UUID、排序、CAA UI 等仍只消费 Host 已解析的工作目录和 Ignore 结果；本次不改领域算法。

## 3. 视觉与无障碍

- 第二 Block 使用一行紧凑控件：下拉占剩余宽度，文件夹与齿轮为独立、有标题和 `aria-label` 的图标按钮。
- 第一与第三个 Shell Header 继续使用已锁定的 VS Code Section 基线；目录行沿用相同全宽分隔线，在原箭头位置使用静态 16px 文件夹图标以对齐标题并表达固定目录上下文；它不可点击，目录行固定为单行且不提供空的 Body。
- 设置 View 的内部 Block 先使用本地语义化 `details`（Wing 尚无可消费的 Shell/Section Block），但必须以显式 16px SVG 箭头、连续上下分隔线、Section Header 主题色和旋转 disclosure 表达，可独立折叠；不使用松散卡片外边距。
- 窄侧栏中目录名称整体省略，文件夹与齿轮始终可达；键盘 Tab 可进入下拉、文件夹、齿轮和设置内每个 disclosure。

## 4. 实施步骤

1. 将第二 Shell 标题、ARIA 和规则文案改为“目录”，将其收为无箭头、无 Body 的单行目录控件，并删除其常驻 Ignore DOM。
2. 将既有 `environmentSettings` 逻辑工具升级为用户可见的“设置”；旧 `ignoreSettings` 命令作为兼容入口统一路由到它，避免迁移已有命令与状态处理。
3. 在设置工具内以“Ignore 管理 → 工程环境 → 插件设置”顺序承载现有 Ignore/环境能力；每项独立折叠。
4. 目录行唯一齿轮打开该工具；不要重复创建 VS Code View、编辑器 View 或第二个齿轮入口。
5. 更新 Shell/设置工具自动测试、文档索引与人工点检表。

## 5. 验收

- [x] 第二 Block 只占一行，文案为“目录”，显示当前目录、下拉、文件夹和齿轮。
- [x] 第二 Block 不再常驻显示 Ignore 管理内容。
- [x] 目录行唯一齿轮打开“设置”当前工具 View；View Title 不再显示重复齿轮。
- [ ] 设置内 Ignore 位于第一项，Git Ignore/插件 Ignore 与原有规则编辑能力不回归。
- [ ] 设置内部各项可独立折叠，窄侧栏和键盘焦点可用。
- [ ] 三个 Shell Block 数量、顺序、第三 Block 的内部滚动与 `×` 语义不变；工具栏和当前工具仍可折叠，目录行固定为单行。
- [ ] 工作目录切换后，所有文件工具仍按相同目录和 Ignore 交集工作。
