## 版本边界

`0.8.1` 取代未公开发布的 `0.8.0` 初始测试候选。项目改名核心、`0.7.4` 代码辅助修复以及后续职责与界面整改统一进入一个 Windows 测试包；不上传两套候选，不制造额外 tag。

Phoenix Wing Registry 根包最新为 `0.7.2`，但 Auto 不直接依赖根聚合包。正式 manifest 与 lockfile 继续精确消费 Registry 已发布的 `@phoenix-wing/code-core`、`git-core`、`git-node`、`kt-codegen` `0.6.4`，以及 `run-core`、`run-node` `0.6.3`。不得写入本地路径、`link:`、`file:`、workspace override 或本地 Wing 回退。

## 本轮内容

- 对外名称统一为 **项目改名**，入口是 Primary 当前工具 Header 中标题与关闭按钮之间的紧凑上下文按钮；创建任务时带入当前目录、名称和启用规则，但不自动分析。一个 Editor View 仍固定一个目录任务，重复点击只聚焦，关闭后才可为另一目录创建任务。
- Primary 保留适合 CAA、C++ 与简单 Web 项目的精确搜索替换、最近 50 组 Source/Target，以及由按钮展开的常用变形 Block；Pascal、小写、全大写、空格、kebab、snake 使用可编辑的 Source/Target 双输入框，可分别勾选、排序或删除。
- Primary 最近记录支持删除所选和确认后清空；下拉框、按钮、输入框使用 VS Code 深色、浅色与高对比主题变量。
- CAA/C++ 项目的源/目标前缀与 I/E 规则，以及复杂 Web 项目的多变形、规则档案、常用/自定义规则、智能候选和完整项目方案统一进入 **项目改名** View。项目方案按目录隔离，最近 20 组只恢复草稿，不自动分析或写盘。
- View 使用固定 Header、可折叠 Block、统一 Source/Target 栅格，以及单行六列、内部横向滚动和固定操作列的紧凑结果布局。
- View 的最近记录、删除、清空、**全不选 / 全选**与派生收进改名方案 Header；**+ 规则 / 常用 / CAA** 收进默认折叠的项目档案 Header。内容区不再保留独立快捷操作行，固定派生规则不显示无效删除按钮，自定义规则仍可删除。
- 文本写盘前由 Host 从冻结报告构建只读虚拟文档，并用 VS Code 原生 Diff Editor 对比。打开前复验原文件 SHA-256、编码和命中数；任何漂移都会拒绝预览并要求重新分析。
- 成功写盘后的 Git 对比继续复用 VS Code 原生 SCM。写盘前计划预览与写盘后仓库审查职责明确分开，均不自动暂存或提交。
- 结构化词段和只读正则发现只保留为第二阶段可行性设计；本候选不开放裸正则写盘。

## Phoenix Wing 0.7.2 适配

- 本地开发必须通过 sibling `phoenix-wing@0.7.2` 构建六个包；esbuild metafile 要证明全部预期输入来自并列仓库且 consumer `node_modules` 命中为 0。
- 正式 VSIX 使用 committed lockfile 与 Registry 精确版本构建，不把本地 Wing 产物当作发布来源。
- Auto 正式构建、Registry 对照和发布不依赖 CAD 仓库。

## Windows 用户测试重点

1. 在 Primary **搜索替换**中检查【项目改名】按钮入口；点击 **常用变形**展开规则 Block，验证 Pascal、小写、全大写、空格、kebab、snake 的双输入框、勾选、排序、删除与实际命中一致。
2. 验证 Primary 和项目改名 View 共用最近 Source/Target；可删除所选与确认后清空，按目录保存的完整项目方案可恢复名称、前缀与规则，但不会自动扫描或写盘。另在 Primary 选择工作区子目录后打开项目改名，确认 View 绑定该子目录且不重复拼接目录名。
3. 检查固定 Header、各折叠 Block、Source/Target 上下对齐、单行结果、横向滚动和固定的 **对比 / 打开**操作列；覆盖 280、360、560、760px 与深色、浅色、高对比主题。
4. 对 UTF-8、UTF-8 BOM、GBK 文本执行写盘前 **预览差异…**；确认原生 Diff 内容准确且磁盘未变化。分析后修改原文件，确认 SHA-256 漂移会阻止预览与执行。
5. 验证点目录、二进制、大文件、symlink、20,000 项上限、200 行分页、路径冲突、Git 脏状态和取消行为。
6. 在非当前工作区克隆中验证根目录单层改名；当前工作区根目录只能提示，不能直接改名。
7. 成功写盘后使用 **Git 对比**审查实际变更，确认不会自动暂存或提交；复扫达到目标后再结束任务。
