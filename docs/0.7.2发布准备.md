## 版本边界

`phoenix-wing@0.7.1` 是 Wing 的根聚合包版本，不是 KT Auto Code 的直接依赖。Auto 正式 manifest 继续精确消费：

| 包 | Registry 版本 |
| --- | ---: |
| `@phoenix-wing/code-core` | 0.6.4 |
| `@phoenix-wing/git-core` | 0.6.4 |
| `@phoenix-wing/git-node` | 0.6.4 |
| `@phoenix-wing/kt-codegen` | 0.6.4 |
| `@phoenix-wing/run-core` | 0.6.3 |
| `@phoenix-wing/run-node` | 0.6.3 |

本补丁不升级 Wing 依赖，只修复 Auto 消费与 Host 行为：Git 深层预选自动补页、移除误导性的 refs 范围下拉、统一头文件引用修正名称、固定 CAA RADE `intel_a` 厂商脚本目录，以及补充 CAA 插件设置只读摘要。正式 manifest/lockfile 不允许本地路径、override 或 Registry 外回退。
