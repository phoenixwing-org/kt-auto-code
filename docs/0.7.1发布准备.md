## 版本边界

`phoenix-wing@0.7.1` 是 Wing 的根聚合包版本，不是 KT Auto Code 的直接依赖。Auto 的正式 manifest 只消费以下 exact scoped 包：

| 包 | 当前 Registry | 发布后目标 |
| --- | ---: | ---: |
| `@phoenix-wing/code-core` | 0.6.2 | 0.6.4 |
| `@phoenix-wing/git-core` | 0.6.2 | 0.6.4 |
| `@phoenix-wing/git-node` | 0.6.2 | 0.6.4 |
| `@phoenix-wing/kt-codegen` | 0.6.2 | 0.6.4 |
| `@phoenix-wing/run-core` | 0.6.2 | 0.6.3 |
| `@phoenix-wing/run-node` | 0.6.2 | 0.6.3 |

四个 `0.6.4` scoped 包和两个 `0.6.3` Run 包均已实际发布。Auto manifest/lockfile 已按上表精确升级；本地联调仍只通过受控 sibling Wing wrapper，绝不提交本地路径。
