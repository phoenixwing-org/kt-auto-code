# KT Auto Code 0.8.2 编译工具发布归档

状态：Windows 发布候选。

## 发布内容

- 代码辅助增加编译工具 View，使用原生 `<details>/<summary>` 内容块。
- 使用 schema 2 项目表统一管理仓库与构建目录，支持多选目录、当前目录探测、相对路径保存和逐行探测、运行、移除。
- 显示仓库分支、Commit、Origin 和工作区状态；Root、3rdParty 及每个项目可独立决定是否更新和目标分支。
- 自动识别 Git、CMake、CAA、`linkCAA.ps1` 与 `linkOut`，并预选适用操作。
- 仓库更新与 Export 内部并行；支持 CMake → CAA 分阶段执行，或 CMake 与 CAA 全并行执行。
- 项目脚本从自身目录无参数运行；单项失败不阻断其他任务，最终统一汇总。
- 插件固化 `scripts/auto-build/Invoke-AutoBuild.ps1`，可显式同步到 Root，也可导出工作目录下的 `Invoke-AutoBuild.local.ps1` 脱离 UI 执行。
- Run 增加 build、objects、`*.obj` 快捷清理；编译 View 增加 Root 前缀头文件、DLL、LIB 清理，均跳过 `.git`。
- PowerShell 子进程和导出脚本兼容 Windows PowerShell 5.1 与 UTF-8 输出。
