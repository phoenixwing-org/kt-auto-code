## 优先手工点检

1. 编译工具预检：配置编辑、项目路径、保存/重载一致；预检不执行 PS1。
2. 项目行“更新”：仅所选仓库更新，其他项目和编译不启动；脏仓库保留文件并提示跳过。
3. 整体启动：仓库任务显示 TS Git；失败仓库有独立记录，其他独立仓库继续；不出现 Invoke-AutoBuild.ps1 启动。
4. macOS 标准 CMake：先用无自定义 mk 动作的工程，取消 Debug 只编 Release；输出在相邻 build/<项目名>Release。重新保存/打开仍只选 Release；双选时按 Debug、Release 构建。
5. 非 Windows export.ps1、linkCAA、CAA 显示“已跳过”与具体原因，随后 CMake 继续；缺依赖时显示真实错误。停止后不应启动后续任务，单独重试不受旧失败记录误阻挡。
6. 项目改名：方案增删/清空、表格对齐、分析/Diff/执行/结束、错误及气泡提示日志；未提交 Git 改动的确认不能误当作强制清理授权。
7. 自动代码：Primary“全部应用”、Right“应用”；打开、导入、保存/重载、预检、源码定位、运行锁及主题。重点试保存尚未完成时继续编辑，新草稿不可丢失或误标已保存。
8. Combo：逐行删除/全清空、键盘、底部弹层避让；清理对话框：方式直达、目标切换、预览、取消与风险确认。真删除只在准备好的临时副本中测试。
9. 头文件：Primary 三个文字按钮、两字目录标签“依赖/工程”、推导/选择、Ignore 三来源及独立“结果”Block；Right 提示行下直接表格，最右固定“状态 / 操作”列。点行和“打开”均定位源码；批次写入后保留原表并标已写入，取消仍待写入，异常待核对；只有再次预览才重扫。用可恢复目录验证规则变化必须重新预览；嵌套 `.gitignore` 聚合未在本版扩展。
10. Git：默认 2 条 commit，更多记录可展开；简报以 Combo 当前仓库为准，空选/失效不留旧简报。登记、刷新、切换、移除外部登记、递归搜索与停止；移除只删登记，不删除磁盘仓库。
11. 项目改名：Primary 最下方目录固定说明；更换任务目录须关闭 Right 再打开。无工作目录启动可首次选择；Primary `×` 不是关闭 Right。
12. Run：首行“刷新 / 清理”；原 build、objects、`*.obj` 三项点击即执行、不询问。只能在可丢弃副本中点检；Git 对话框不执行 reset，与 AutoBuild 强制恢复区分。
13. CAA Combo：生成代码改用 `GetComboSelectNotification()`；读写值及初始化行为不变。Windows/CAA 中验证选择项后通知及取值，见[简版 BUG 记录](bug/自动代码-CAA-combo的信号问题.md)。
14. 关闭联动：分别关闭项目改名、编译工具、头文件 Right，确认对应 Primary/Open Item 消失，回退 MRU；最后一项关闭后回欢迎页。后台 Right 关闭不改变当前工具或焦点；同工具仍有其他 Right 时保留。自动代码 JSON 不受此规则影响，Primary `×` 不反向关闭 Right。
15. 目录重开：头文件 Right 开着时切换上方目录，内部工程路径不变；关闭 Right 后再开，采用当时的上方完整目录，不再需要额外关闭残留 Primary。
