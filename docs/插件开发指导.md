## 按钮呈现

Primary 和 Right 的业务按钮默认以文字为主。只有用户明确要求时，才使用纯图标或“图标＋文字”。

原因：图标辨识度低，用户容易猜不出功能；Primary 空间有限，文字更直接。

本规则不改变已约定的外层导航及通用关闭、折叠控件。

## 主题适配

保留布局，减少自定义配色，优先使用 VS Code 主题变量；选中项的副文字和徽标继承选中字色，不写死明暗主题颜色。

详细布局见[前端开发规则](前端开发规则.md)，分页面进度见[UI TODO 备忘](0.9.0-Right工具Primary迁移点检.md#11-2026-09-09-分页面-todo-备忘继续工作先读此表)。
