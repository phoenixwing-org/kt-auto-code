# KT Auto Code 0.7.3 发布准备

状态：ready（本地 Registry/VSIX 门禁已通过；等待用户安装抽检与手动发布）

Owner：KT Auto Code maintainers

## 版本边界

本补丁不升级 Phoenix Wing Registry 依赖，也不写入本地路径、`link:`、`file:`、workspace override 或本地 Wing 回退。正式 manifest 继续精确消费已发布的 `@phoenix-wing/code-core`、`git-core`、`git-node`、`kt-codegen` `0.6.4` 与 `run-core`、`run-node` `0.6.3`。

## 本轮内容

- Git 合并区间由纯分支 first-parent OID 模型判定；唯一非当前本地分支须由用户确认切换后重新执行 Wing 安全预检。
- Git 合并 View 将秒级时间戳格式化为本机日期时间；切换分支后按 OID 重投影选择，图形车道只负责展示，不作为是否可改写的依据。
- 提交图增加分支胶囊、HEAD 空心节点、平滑曲线和连续区间拖动柄；提交行菜单只保留复制完整简报与安全重置本地未发布提交时间。
- 合并提交信息默认清理多余空行并同步 Author/Committer 身份与时间；仍可取消同步后分别编辑。
- Run 当前工具 Block 修复滚动边界；CAA 诊断进入 Problems 的严重级别和并发 MK 保护明确化。
- 头文件引用修正按 `ROOT_DIR_INCLUDE` 优先、`ROOT_DIR + SDK_PREFIX + core/include` 回退推导，并提供必要的冲突/跳过/预览/写入日志。
- 新增[必要日志输出规则](必要日志输出规则.md)，限制默认日志为用户可操作的开始、结果、警告与错误。

## 重点人工点检

1. 在两条本地分支各准备普通 first-parent 直线提交：当前分支连续选择可直接预检；另一分支连续选择显示目标分支，确认切换后重读提交图并预检。
2. 选择不连续、跨分支或 merge 节点，确认 checkbox/拖动的界面预览不替代纯模型判断，错误记录到 Output，且工作树不写入。
3. 合并 View 的 commit 元数据时间显示本机 `YYYY-MM-DD HH:mm`，不显示纯秒值。
4. Run 长项目树内任意位置滚轮可连续滚动当前工具，不需要移到 Primary 页边缘；同一时段启动第二个 CAA MK 应明确阻止。
5. 头文件引用修正分别用 `ROOT_DIR_INCLUDE` 和 `ROOT_DIR + SDK_PREFIX` 推导；检查 Output 中包含路径、映射数、冲突和跳过项。
6. 在当前本地未发布直线历史的中间 commit 使用“复制简报”和“重置提交时间…”；确认输入对话框可取消，执行后 Author/Committer 时间相同、后续 commit 时间与最终 tree 不变，并保留备份 ref。被 remote、其他分支或 tag 引用时必须阻断。
