# 0.9.2 Git 合并区间原型计划

状态：待实施；2026-09-10 用户明确从 0.9.1 移入本版

Owner：KT Auto Code maintainers

## 范围

补齐 Webview Preview 中 Git“合并区间”的 Right 原型，复现 0.9.1 已确认的正式行为。此计划不代表新建 0.9.2 分支或功能已经完成；0.9.1 本地内测不等待本项。

- [ ] Primary 点击“合并区间”有响应，打开对应 Right；重复打开、关闭、返回和状态保留规则明确。
- [ ] 使用内存提交样例呈现当前分支顶部向下的可达历史与合入分叉，兼顾时间排序和拓扑；不提供全部分支混合图。
- [ ] 当前分支 combo 模拟确认、取消、成功清空旧勾选，以及脏工作树/其他 worktree 占用等失败提示；不执行真实 checkout。
- [ ] 模拟分页、主线连续区间选择、非主线置灰禁选、预检及状态反馈；不要求区间从 HEAD 开始，不执行真实合并或改写。
- [ ] 对齐长说明截断、右侧元信息、remote 点击详情、长文本 500ms 延迟提示及普通分支标签样式。
- [ ] 通过共享 Host-neutral 展示模型/组件复用正式效果，Preview 数据与模拟执行留在 adapter，不能进入正式 bundle。
- [ ] 自动验收取消、迟到响应、关闭/重开、切换分支和分页；浅色/深色/高对比及窄栏由用户分别点检。

## 停止线

不重做 Git 算法、正式工作树安全校验或外层 Shell，不接真实文件写入或 Git 历史改写。原型确认不替代真实 Host 验收。

清理快捷栏、Phoenix 缓存清理的执行范围仍须另行研究，不因本计划自动纳入 0.9.2 实现。
