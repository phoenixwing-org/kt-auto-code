## 实现与状态规则

- 正式 `KtcGitSquashViewController` 只保留 VS Code Panel 生命周期、CSP/nonce 和消息桥；`KtcGitSquashViewModel` 与 `KtcGitSquashViewHtml` 共享原 DTO、消息守卫、HTML/CSS/交互。未修改 Git Controller 的仓库读取、切换、合并算法或资格规则。
- Preview `previewGitSquash` 用仅 `allow-scripts` 的 sandbox iframe 加载同一 HTML。只接受本 iframe、当前 channel 的消息；每次渲染及关闭使旧消息失效。nonce CSP 禁止外部脚本；不把原型 adapter、夹具或模拟桥接接入正式入口。
- 真实浏览器发现 `srcdoc` 继承父页面 `script-src 'self'`，子页面单独设置 nonce 不能放宽父策略。受控 Preview server 现在为每次 HTML 响应产生随机 24-byte nonce，写入父 CSP 和专用 meta，由 iframe 复用；非 HTML 响应不增加 nonce，缺凭据时拒绝渲染并要求重启/刷新。不增加脚本 `unsafe-inline` 或 sandbox `allow-same-origin`。
- 图轨道与预检分别复用 Wing 的 `pnwProjectGitCommitGraphRows`、`pnwPlanGitSquash`，数据完全来自内存。选择复用 Auto 的既有主线区间投影；无需重写图布局或区间算法。远端徽章仍只表达本地跟踪引用样例，不代表实时远端状态。
- 首次打开默认加载 5 条；分页保留选择，中段预检显示后续重放。合并提交、根提交或需重放 merge 的区间仍由纯预检阻止。执行按钮只展示反馈并保留示例历史，不声称真的改写。
- 同仓库重复打开只恢复现有 Right；其他仓库必须先关闭旧 View，不静默换仓库。隐藏或切换 Editor 保留内存状态；关闭后重新打开建立新会话和空选择，Preview 整页重置/重载不持久化此临时 Right。
- 分支切换成功后同步同一仓库的 Primary 内存快照（分支、HEAD、上游、近期提交），与正式 Host 重读并推送状态的行为一致；不切走 Primary 当前所选的其他仓库，不重新激活已关闭的 Primary，不重新登记已移除仓库。取消、失败和过期回包不发布快照。Right 保存每仓库的原始样例底稿，关闭重开或切回分支不会在更新后的快照上重复追加 topic 样例；底稿与快照均不写磁盘。
- Git Right 的关闭只释放自己的模拟会话，不改变已批准的三个任务型 Right→Primary 关闭规则；关闭 Git Primary 不隐式关闭已打开的 Git Right。
- 原型顶部提供干净、未提交、其他 worktree 占用、切换失败和延迟场景。场景变化废弃旧预检；预检失败清空旧 draft，执行仍复验状态/分支/HEAD/选择。延迟操作可取消，关闭/重开后的迟到结果不能复活旧 Right。

## 停止线

不重做 Git 算法、正式工作树安全校验或外层 Shell，不接真实文件写入或 Git 历史改写。原型确认不替代真实 Host 验收。

清理快捷栏、Phoenix 缓存清理的执行范围仍须另行研究，不因本计划自动纳入 0.9.2 实现。
