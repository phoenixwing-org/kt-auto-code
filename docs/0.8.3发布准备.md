## 本轮候选内容

- Primary 统一 Ignore：插件内置、Git、自定义三个来源独立启停；原生 View Header 固定 Ignore 与 Settings，Ignore 打开独立工具 View且不增加第四个一级 Block。Ignore View 支持 Git/Phoenix 写入目标、合并规则、智能去重、逐条增删和末尾紧凑推荐区。
- 头文件引用修正、编码、搜索替换和项目改名共用 Ignore 运行选择；内置列表补齐 CAA、CMake、Visual Studio 和常见生成目录。
- 项目改名冻结实际 Ignore 规则，补写盘前 Diff 的 UTF-8 BOM/GBK 不落盘验证、立即取消与迟到结果隔离、非法路径组件、硬链接和 dangling symlink 安全边界。
- 项目改名第二阶段仅加入受限的结构化名称只读发现算法与文档；不开放裸正则写盘，不把待评审候选混入 Apply。
- 发布工具要求显式版本与完整 commit OID；最终回执必须绑定 Registry VSIX 的版本、来源 commit、文件数、字节数和 SHA-256，并拒绝本地 Wing 或脏源码候选。
