# 0.4.0 单 Block 编码试点点检

## 试点目标

以“编码修正”验证接近 VS Code Search/Git 的单 Block 工作流：Block 标题和命令位于顶部，原编码操作界面位于上部，状态与文件结果紧随其下。预检或转换只更新当前 Block，不创建第二个结果 Block。

试点通过前，不批量迁移头文件 ASCII、搜索替换、Ignore、成员排序、UUID 或 CAA。

## 推广判定

只有以下条件全部满足才推广：

1. 控件密度和结果可读性不低于现有界面。
2. 预检、转换和文件打开没有功能回退。
3. 没有双 Block、自动跳转或结果闪烁。
4. 用户人工确认该结构符合预期。

推广时按复杂度分两类：搜索替换等保留完整多控件操作区；成员排序、UUID、CAA 使用紧凑操作区，但预留后续选项位置。
