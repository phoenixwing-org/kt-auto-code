# 0.1.0 插件市场发布归档

- 版本：`kuntai.kt-auto-code` 0.1.0，已发布到 Visual Studio Marketplace。
- 提供头文件 ASCII 修正、文件编码修正、Ignore 设置与工作区搜索替换。
- 搜索替换支持关联规则、冲突预览、ASCII→UTF-8 / GBK 默认编码选择。
- Side Bar 支持 Ribbon 与小图标两种工具栏样式，Header 可切换。
- 新增 C++ 成员排序扫描入口，排序核心共享化仍处于 POC 阶段。
- 补齐 Gitee 仓库、主页、Issues、README、CHANGELOG、NOTICE 与 Apache-2.0 信息。
- 已验证扩展构建、根单元测试与 VSIX 打包；发布后以 Marketplace 页面为准。
