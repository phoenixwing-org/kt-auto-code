# 0.4.0 单 Block 成员排序点检

## 目标

“C++ 成员排序”只使用一个 Sidebar 模块 Block：上部是扫描、应用和筛选区，下部是缓存结果。扫描、应用和还原只能更新当前缓存，不得关闭当前 Block、重新扫描、自动打开多个 Diff，或创建第二个结果 Block。
